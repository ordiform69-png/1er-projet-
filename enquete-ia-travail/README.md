# IA et robotique : la France est-elle prête à la fin du travail tel que nous le connaissons ?

Enquête prospective documentée, état au 13 novembre 2026.

| Fichier | Contenu |
|---|---|
| `IA-robotique-travail-France.pptx` | PowerPoint 16:9 entièrement éditable : 22 diapositives principales et 4 annexes, graphiques natifs, sources en pied de page, détails dans les notes de l'orateur |
| `IA-robotique-travail-France.pdf` | Version PDF, prête pour un envoi par courriel |
| `note-de-synthese.pdf` (et `.html`) | Note d'une page, lisible en 3 minutes |
| `registre-des-preuves.md` | Annexe de vérification : affirmation, source, URL, date, méthode, niveau de confiance |
| `CONTRE-EXPERTISE.md` | Corrections apportées et faiblesses résiduelles |
| `message-accompagnement.md` | Message de présentation pour un journaliste ou un parlementaire |
| `src/build-deck.js` | Script de génération du PowerPoint (pptxgenjs) |

```
NODE_PATH=<dossier node_modules contenant pptxgenjs> node src/build-deck.js IA-robotique-travail-France.pptx
```
