# Petit guide de survie

Livret de survie illustré, en français, utilisable **hors ligne** :

- `guide-survie/guide-survie.html` — version web autonome (aucune connexion requise, mode sombre, imprimable).
- `guide-survie/guide-survie.pdf` — version PDF au format A5 (60 pages), à garder sur le téléphone ou à imprimer.

Chapitres : priorités, kit, abri, feu (dont 5 techniques d'allumage : briquet, pierre à feu, lentille, pile + paille de fer, archet), eau, orientation, signaux, premiers secours, nourriture, plantes utiles (et sosies toxiques), techniques issues de l'armée, nœuds, fabrications simples (filtre à eau, SODIS, alambic solaire, boussole improvisée…), météo, survie en montagne, survie en mer, check-lists.

> Ce livret ne remplace pas une formation aux premiers secours. En cas d'urgence : **112**.
