# Petit guide de survie

Livret de survie illustré, en français, utilisable **hors ligne** :

- `guide-survie/guide-survie.html` — version web autonome (aucune connexion requise, mode sombre, imprimable).
- `guide-survie/guide-survie.pdf` — version PDF au format A5 (40 pages), à garder sur le téléphone ou à imprimer.

Chapitres : priorités, kit, abri, feu, eau, orientation, signaux, premiers secours, nourriture, plantes utiles (et sosies toxiques), techniques issues de l'armée, nœuds, météo, check-lists.

> Ce livret ne remplace pas une formation aux premiers secours. En cas d'urgence : **112**.
